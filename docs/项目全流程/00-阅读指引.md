## 三、文中的标记怎么读

### 证据强度四档

| 标记 | 含义 | 使用方式 |
|---|---|---|
| **多源验证** | 有多个独立来源支持 | 可以作为当前结论使用 |
| **单一来源** | 只有 1 个来源，或来源之间未交叉验证 | 可以参考，不要当成行业共识 |
| **经验起点** | 无外部来源，是项目设定的起始值 | 必须用实际数据重新校准 |
| **待补 / 未验证** | 明确还没验证 | 不要当成结论，更不能直接自动化 |

**关键提醒**：广告优化领域最危险的做法，是把「单一来源」和「经验起点」当成「多源验证」。文中保留这些等级，就是为了让边界可见。

### 事实 vs 推断

- **事实**：能追溯到代码、实测记录、官方文档、公开实现或仓库内产物。
- **推断**：文档作者的判断，通常会明确标注「推断」「建议」或「这是本文作者判断」。

阅读时请把两者分开：事实可以用来复核，推断只能作为决策输入。

## 四、术语速查

| 术语 | 一句话 |
|---|---|
| **ACoS** | 广告花费 ÷ 广告销售额，衡量广告自身效率 |
| **TACoS** | 广告花费 ÷ 总销售额（含自然订单），衡量广告对整店的影响 |
| **盈亏平衡 ACoS** | 广告前单位贡献 ÷ 售价；超过它通常意味着贴钱 |
| **目标 ACoS** | 在盈亏平衡线上再留出目标净利后的经营目标 |
| **可接受 CPC** | 售价 × 转化率 × 目标 ACoS，是出价上限的参考线 |
| **动态点击阈值** | 1 ÷ 转化率，用来判断样本是否足够下结论 |
| **收割** | 把已验证的搜索词迁到独立 Exact 活动，便于单独控制出价 |
| **份额漏斗** | SQP 报告的曝光、点击、加购、购买份额，用于定位短板环节 |
| **影子层** | 决策模型只提供第二意见，不进入规则层主决策路径 |
| **分歧检测** | 规则层与影子层判断不一致，这本身就是「案例模糊」的信号 |
| **门控** | 按置信度阈值决定自动执行、人工复核或待标定 |
| **处置** | 对单条分析结果的最终流转建议：自动执行 / 人工复核 / 待标定 |
